# V3.1 维护 + 观察期 实施方案（v2，应用 7 项修正）

先确认你这次审查最重要的一句话：

> **Message Protocol Contract 会成为继 Kernel ABI 之后第二个长期冻结资产。**

这句话定住了 V3.1 的真正价值。它不是"补两个 bug"，而是**建立 AgentKit 的第二层 ABI**。第二层 ABI 一旦建错，未来 Context / Memory / RAG / Compact 全部会漂。

7 项修正我全部接受。其中 3 项（M1/M2/M3）我完全同意并做了精确化，另外 4 项（M4/M5/M6）采纳并补齐了具体规则。

## 二、关键修正的详细说明

### M1 — Message Protocol Contract 的定位

**V3.1 冻结为**：

```text
┌─────────────────────────────────────┐
│  Kernel Message Types               │   （kernel/types.py）
│  Message / ToolCall / ToolCalls     │   ABI Freeze
└──────────────┬──────────────────────┘
               │
               ▼
┌─────────────────────────────────────┐
│  Internal Message Sequence Contract │   （docs/contracts/message_protocol.md）
│  I1 / I2 / I3 / I4 / I5             │   Contract Freeze（V3.1 起）
└──────────────┬──────────────────────┘
               │
               ▼
┌─────────────────────────────────────┐
│  Provider Adapter                   │   （models/*.py）
│  将内部序列转换为 provider-specific │   每 Provider 独立
└──────────────┬──────────────────────┘
               │
               ▼
┌─────────────────────────────────────┐
│  External Provider Protocol         │   （OpenAI / Anthropic / ...）
│  各自有各自语义                     │
└─────────────────────────────────────┘
```

**关键约束**：

> AgentKit 只冻结**内部序列契约**。Provider 语义差异（system 位置、empty content、parallel 语义等）全部由 Adapter 承担。**Contract 不承诺跨 Provider 一致性**。

**理由**：一旦写成"跨 Provider 契约"，未来若发现 Anthropic 对某种序列的语义与 OpenAI 不同，就得改 Contract。**这不是 Contract 的失败，是 Contract 定位错了。**

### M2 — Retry 判断的精确化

**V3.1 冻结**：

```text
metadata 中的字段：error_class（str）

V3.1 冻结的唯一值：
  "policy_denied" —— 明确拒绝，RetryExecutor 不重试

未定义值的行为：
  按默认语义（error=True 且无 error_class → 重试）

RetryExecutor 判断规则：
  if last.error and last.metadata.get("error_class") == "policy_denied":
      return last
  # 其他 error=True → 走原有重试逻辑
```

**关键点**：

1. **字段名 `error_class` 冻结** —— 第三方工具知道该写什么
2. **只冻结一个值 `"policy_denied"`** —— 其他分类留给 V4
3. **未定义值走默认重试** —— 保守，不破坏 V2 语义
4. **不再看 `metadata["blocked"]`** —— 弱类型判断已废弃

**`PermissionExecutor` 输出**：

```python
ToolResult(
    tool_call_id=call.id,
    content=f"[blocked by policy] {call.name}",
    error=True,
    metadata={
        "error_class": "policy_denied",     # 唯一允许的标记
        "policy": self.policy.name,         # 额外信息（不参与判断）
    },
)
```

### M3 — Message Sequence Contract 的完整 invariant

**V3.1 冻结五条**：

```text
I1. Role Dependency
    sequence 不以 tool 消息开头。
    任何 tool 消息必须有前置 assistant(tool_calls)。

I2. Call Identity Preservation
    ∀ tool 消息 m：
        ∃ assistant 消息 a，其 tool_calls 包含 m.tool_call_id。

I3. Transform Closure
    ∀ Transform T，若 Valid(messages)：
        Valid(T(messages))
    （所有 Transform 必须满足）

I4. Tool Result Ordering
    若 assistant 消息声明 tool_calls = [A, B, ...]：
        在下一个 assistant 消息出现之前，
        所有 A、B、... 的 tool result 必须全部出现。

    合法：
      assistant(tool_calls=[A, B])
      tool(A)
      tool(B)
      assistant(next)

    合法（顺序可交换）：
      assistant(tool_calls=[A, B])
      tool(B)
      tool(A)
      assistant(next)

    非法：
      assistant(tool_calls=[A, B])
      tool(A)
      assistant(next)          ← B 缺失
      tool(B)                  ← 迟到

    非法：
      assistant(tool_calls=[A, B])
      assistant(next)          ← 都没有

I5. Call ID Uniqueness
    在一次 history 内，所有 tool_call_id 唯一。

    范围限定：单次 history（ctx.messages）。
    不是 session 全局。
    理由：history 可能被截断，截断后不同轮的 id 可重复。
```

**为什么只有五条**：

> 契约不是越多越好。每多一条，就要多一个测试，多一次维护。**五条覆盖了 V1→V3 真机上暴露的所有序列问题。**

**未来如何扩展**：

```text
任何新增 invariant：
  1. 必须有真实信号支撑（V4 Entry 规则）
  2. 必须能写成 property test
  3. 走独立的 Contract Change Review
```

#### 3.1.2 修复 ①：Permission × Retry（M2 修正后）

**问题**：

```text
PermissionDenied
    ↓
error=True 的 ToolResult
    ↓
RetryExecutor 对 error=True 重试
    ↓
确定性拒绝被计进重试预算
```

**Invariant（写进 `executor/retry.py` docstring）**：

```text
RetryExecutor 只对"瞬时"执行失败重试。
Policy-level 拒绝（如 Permission）不是瞬时失败，
不应消耗重试预算。

判断依据：ToolResult.metadata.error_class
  - "policy_denied" → 不重试
  - 其他值 / 无值  → 按默认语义（重试）
```

**两段提交**：

**Commit A**：

**Commit B**：

```python
# executor/retry.py
class RetryExecutor:
    async def execute_one(self, ctx, call):
        last = None
        for attempt in range(1, self.max_attempts + 1):
            last = await self.inner.execute_one(ctx, call)
            if not last.error:
                return last
            if last.metadata.get("error_class") == "policy_denied":
                return last
            if attempt < self.max_attempts:
                await asyncio.sleep(self.backoff * attempt)
        return last
```

**Commit B**：

```python
# context/transform.py
class BudgetTransform:
    async def apply(self, messages):
        current_task_idx = self._find_current_task(messages)
        kept = self._greedy_keep(messages, self.max_tokens)
        if current_task_idx is not None and current_task_idx not in kept:
            kept.append(current_task_idx)
            kept.sort()
        return [messages[i] for i in kept]

    @staticmethod
    def _find_current_task(messages):
        for i in range(len(messages) - 1, -1, -1):
            if messages[i].role == "user":
                return i
        return None
```

**`tests/property/message_sequence.py`**：

```python
"""消息序列合法性的公共测试基础设施。

任何 Transform 实现继承此测试基类。
"""
from hypothesis import given, strategies as st
from agentkit.kernel.types import Message, ToolCall


# ── 生成器 ──

@st.composite
def valid_message_history(draw):
    """生成合法的消息序列（满足 I1-I5）。"""
    n_turns = draw(st.integers(min_value=0, max_value=5))
    messages = []
    used_call_ids = set()

    for i in range(n_turns):
        # user
        messages.append(Message("user", draw(st.text(max_size=100))))

        # assistant
        if draw(st.booleans()):
            n_calls = draw(st.integers(min_value=1, max_value=3))
            calls = []
            for j in range(n_calls):
                cid = f"call_{i}_{j}"
                used_call_ids.add(cid)
                calls.append(ToolCall(id=cid, name="tool_x", arguments={}))
            messages.append(Message("assistant", "", tool_calls=calls))
            # I4: 所有 tool result 必须出现
            for c in calls:
                messages.append(
                    Message("tool", "result", tool_call_id=c.id)
                )
        else:
            messages.append(Message("assistant", draw(st.text(max_size=100))))

    return messages


# ── 断言 ──

def is_valid_message_sequence(messages) -> tuple[bool, str]:
    """检查 I1-I5。返回 (is_valid, reason)。"""

    # I1: 不以 tool 开头
    if messages and messages[0].role == "tool":
        return False, "I1: starts with tool"

    # I5: call_id 唯一
    all_call_ids = [
        tc.id
        for m in messages if m.role == "assistant" and m.tool_calls
        for tc in m.tool_calls
    ]
    if len(all_call_ids) != len(set(all_call_ids)):
        return False, "I5: duplicate call_id"

    # I2 + I4: 逐个 assistant 检查
    declared: dict[str, set[str]] = {}   # call_id → 是否已有 result
    i = 0
    while i < len(messages):
        m = messages[i]
        if m.role == "assistant" and m.tool_calls:
            expected = {tc.id for tc in m.tool_calls}
            seen = set()
            j = i + 1
            while j < len(messages) and messages[j].role != "assistant":
                if messages[j].role == "tool":
                    tid = messages[j].tool_call_id
                    if tid not in expected:
                        return False, f"I2: orphan tool_call_id {tid}"
                    seen.add(tid)
                j += 1
            if seen != expected:
                return False, f"I4: missing tool results for {expected - seen}"
            i = j
        else:
            i += 1

    return True, "ok"


# ── 测试基类 ──

class TransformProtocolTestBase:
    """所有 Transform 测试继承此类。

    子类需实现 make_transform()。
    """

    @given(valid_message_history())
    def test_transform_preserves_protocol(self, history):
        """I3: transform closure。"""
        transform = self.make_transform()
        result = self.apply(transform, history)
        is_valid, reason = is_valid_message_sequence(result)
        assert is_valid, f"Transform broke protocol: {reason}"

    def make_transform(self):
        raise NotImplementedError

    def apply(self, transform, messages):
        """同步包装 async transform。"""
        import asyncio
        return asyncio.run(transform.apply(messages))
```

### 3.3 V4 Entry（M6 修正后）

#### 3.3.1 Entry Criteria

```markdown
# V4 Entry Criteria

V4 Proposal 必须满足以下全部四项：

1. 至少 3 个独立真实信号
   来自 docs/signals/，来自冷却期记录
   不能是理论推演

2. 现有 Contract 无法解决
   - Architecture Firewall 拦不住
   - ABI Freeze 不涉及
   - Conformance 不涉及
   - 现有 Protocol 无法承载
   若三者之一能解决 → 不是 V4，是 V3.x patch

3. 提出新的 invariant
   不是新功能，是新的不可变约束
   新 invariant 需要 Contract Freeze

4. 证明不是 V3.x patch
   通过 Rejected Alternatives 字段
```

#### 3.3.2 Proposal Template（含 M6 修正）

```markdown
# V4 Proposal: <Claim 一句话>

## 1. 它解决哪个真实信号？

引用 Signal NNNN / NNNN / NNNN（至少 3 个独立信号）。

## 2. 为什么现有三个防线解决不了？

- Architecture Firewall：为什么不是"某模块越权"？
- ABI Freeze：为什么不是"Kernel 契约需要变"？
- Conformance：为什么不是"Provider 适配问题"？

若三者之一能解决，则这不是 V4。

## 3. 要冻结的新 Contract 是什么？

- 新 Protocol 名 + 方法签名（若有）
- 新 invariant（若有）
- 为什么不属于现有 Protocol 的自然延伸

## 4. Kernel Impact 预判

- 是否需要修改 kernel/？如果需要，为什么？
- 如果不需要，新能力落在哪一层？

## 5. 验收方式

沿用 V3 的四道 Gate：
- Gate A：Kernel ABI 是否仍 frozen
- Gate B：新能力与 V3 三个能力的组合
- Gate C：新 Protocol 对第三方开放
- Gate D：V2.5 Conformance 是否仍通过

## 6. Rejected Alternatives

为什么：
- V3.x patch 不够？
- Runtime extension 不够？
- Existing Protocol 不够？

被拒绝方案：
1. <方案 A> —— 为什么拒绝
2. <方案 B> —— 为什么拒绝
3. <方案 C> —— 为什么拒绝

此字段防止"看到问题就加 Manager / Router / Controller"。

## 7. Why now?

为什么不是继续观察？

- 已观察周期：<N 周>
- 信号数量：<N>
- 若继续观察，预期会新增什么信号？
- 为什么现有信号已经足够启动 V4？
- 若延后 4 周启动 V4，代价是什么？

此字段防止：
  "看到漂亮架构机会就启动 V4"
  而不是"为了解决真实问题启动 V4"

## 8. 立项声明

- V4 Claim（一句话）
- V4 的第一个 Gate
- V4 明确不做什么
```
